Muster

Eine einfache HTML-Präsentation

Bereit für GitHub Pages, QR-Code und Zuschauer auf dem Smartphone.

Prinzip

Eine Datei pro Präsentation

  • Die Präsentation läuft direkt im Browser.
  • Neue Präsentationen entstehen durch Kopieren dieses Ordners.
  • GitHub Pages macht daraus automatisch eine öffentliche Webseite.

Teilen

QR-Code für das Publikum

Sobald die Präsentation veröffentlicht ist, wird aus der endgültigen URL ein QR-Code erzeugt und hier eingebunden.
